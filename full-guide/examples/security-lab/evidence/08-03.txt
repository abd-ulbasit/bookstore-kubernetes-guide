# Transcript for 08-day-2-operations/03-troubleshooting-playbook.md.
# Tier A: a kind cluster the guide's author runs for the guide, shared with
# other parts of the guide. The lab used its own namespace, p08-03-bookstore. The chapter
# names the bookstore namespace and applies the same files; the only changes
# are the namespace name and the .bookstore.svc.cluster.local DNS names in
# the canonical manifests. Lines that name the lab namespace are kept as
# captured.
# Not run here: the kind cluster create and delete, the image build and the
# kind load (the four Bookstore images were already loaded), the NetworkPolicy
# branch (the chapter's diagnosis is not induced in this run) and an OOMKilled
# drill (the bookstore LimitRange sets a 16Mi memory floor).
# The node-level step (step 11) used a second namespace, p08-03-node-debug, labelled
# privileged and registered in security/namespace-exceptions.yaml under the
# name node-debug. The chapter's manifest names it node-debug.
# The debug image is busybox:1.36 pinned by digest. The digest matches the
# registry manifest for busybox:1.36, checked with docker buildx imagetools
# inspect. This header was reworded after the run to state that check; the
# captured lines below are unchanged.
