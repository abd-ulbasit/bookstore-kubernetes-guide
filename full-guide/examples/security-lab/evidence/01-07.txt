# Transcript for full-guide/01-core-workloads/07-jobs-and-cronjobs.md.
# Tier A: a kind cluster with a Kubernetes v1.37.0 node, kubectl v1.37.2.
# The lab cluster is shared, so the lab runs in the namespace p01-07-bookstore.
# The chapter names the namespace bookstore. Each manifest copy here changes
# only the namespace lines shown in the sed expression of its step, and the
# PostgreSQL host name that uses it. The 20- StatefulSet was applied from the
# working tree as it stood at apply time, which held a startupProbe that the
# committed file does not have (see the note at the end of this header).
# Prerequisites from 01.03 to 01.05 are applied first, in chapter order.
# The 35- PriorityClasses are cluster-scoped and carry no namespace.
# Lines that name the namespace are elided with # ... in the chapter.
# Note added after the run. The StatefulSet's recorded last-applied
# configuration shows a startupProbe (failureThreshold 60, periodSeconds 5)
# that the committed 20- file does not have. Without a startup probe, the
# liveness probe can kill Postgres during a slow first initdb. An earlier
# attempt in this namespace showed that restart, and it is not part of this
# record. Two earlier attempts in this namespace were stopped and the namespace
# deleted before this run. A run in the shared namespace p01-bookstore was also
# stopped, because another agent was using that name.
# Teardown: the namespace stayed Terminating after the timed-out wait in the
# last step. The commands after "# end of transcript" were run after the run
# to confirm the namespace was gone.
