# Transcript for appendix/A-kubectl-cheatsheet.md: the commands whose output
# the chapter shows (sections 2 to 6).
# Tier A: a kind cluster on Kubernetes v1.37.0, kubectl v1.37.2. The chapter
# names its cluster bookstore. This lab cluster had a different name, and the
# node name in the output is kept verbatim.
# Substitution: lab-ns-a stands in for the chapter's bookstore namespace, and
# target for the chapter's catalog Pod. The scratch namespace name is redacted
# to lab-ns-a in this copy. The output blocks print no namespace name. Every
# busybox image is pinned by digest, as 01.01 requires.
# Each command is echoed with its arguments, and shell quotes are simplified in
# the echo. "[exit N]" is the command's exit status.

## step 2: ServiceAccount that does not automount a token, and auth can-i
$ cat sa.yaml
apiVersion: v1
kind: ServiceAccount
metadata:
  name: catalog-sa
automountServiceAccountToken: false
[exit 0]
$ kubectl apply -f sa.yaml -n lab-ns-a

[exit 0]
$ kubectl auth can-i get configmap/catalog-config -n lab-ns-a --as=system:serviceaccount:lab-ns-a:catalog-sa

[exit 1]
