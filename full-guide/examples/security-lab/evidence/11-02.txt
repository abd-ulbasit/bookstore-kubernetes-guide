# Transcript for 11-advanced-production-patterns/02-operator-development.md.
# Tier A: a kind cluster named sf-pilot, Kubernetes v1.37.0 server, kubectl v1.37.2.
# Run on 2026-10-31 against the shared lab cluster. Every namespace and every
# cluster-scoped object the run created carries the p11-02 prefix or is the
# chapter's own CRD or ClusterRole name; all of them were deleted at the end.
# Substitution: the chapter prints `acme`, `bookstore-operator-system` and
# `bookstore-tenant-acme`. This run used `p11-02-acme`, `p11-02-operator-system`
# and `bookstore-tenant-p11-02-acme`. The lab copy of the config renamed
# `bookstore-operator-system` to `p11-02-operator-system` and `acme` to
# `p11-02-acme` in every YAML file. The v1alpha1 document was applied from a copy
# that holds only the sample's second document, with `acme-legacy` renamed to
# `p11-02-acme-legacy`. The two dry-runs of the sample use the reader's names.
# The cluster's node name is printed as captured. The chapter says once that its
# output came from a lab cluster with a different name.
# Not run on the cluster: cert-manager, which the lab cluster did not have. The
# serving certificate is a self-signed certificate made with openssl, and the
# CRD's caBundle was patched by hand. The webhook configurations were not applied:
# they intercept Pod creation in every namespace their selectors do not exclude,
# and this cluster is shared. The webhook Service was applied alone, taken from
# config/webhook/manifests.yaml. The Pod admission webhooks were not exercised.
# No heavy install ran, so no heavy lock was taken.
# What did not work the first time: the lab engine stalled on the image build
# for several minutes, and then the module download inside the build hit a TLS
# handshake timeout. The build was repeated and succeeded. An image of the
# unfixed code was not built, so the missing /convert route was not seen live.
# The fix is shown by the manager's `Conversion webhook enabled` line and by the
# conversion round trip. Under load, some reads timed out, returned EOF, or (once)
# returned Forbidden to the cluster-admin identity. Each one was repeated, and the
# repeat is kept below the failure.
# Mac-side lines run on the author's Mac, not the cluster: the lines that start
# with `cd "$OP"` or `cd "$WT"`, and the controller-gen runs in the scratch copy.
# `$OP` is the operator directory and `$WT` is the worktree root. The envtest
# binaries for 1.37.0 came from setup-envtest.
# Versions: controller-runtime v0.25.2, client-go v0.37.2, controller-tools
# v0.22.0, kustomize v5.8.1 (bundled in kubectl), setup-envtest release-0.25.
# The manager image is bookstore/operator:dev, built from the committed Dockerfile
# with its base images pinned by digest, and loaded into the lab node.
# Lines that begin with `[exit N]` are not command output. They mark a non-zero exit.
