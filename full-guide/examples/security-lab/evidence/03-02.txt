# RABBITMQ_DEFAULT_PASS and AMQP_URL. rabbitmq reads the first two, and orders
# and payments-worker read AMQP_URL, all by secretKeyRef. The run above did not
# cover them. These two runs did, on the same kind cluster, in the namespace
# p00-shared-raw. The chapter names bookstore. Lines that name the lab
# namespace are kept as captured. No credential is printed: each one was
# generated at apply time by openssl and the transcript shows key names only.
# The orders and catalog images were rebuilt from this tree under a tag of their
# own, bookstore/orders:p00-shared and bookstore/catalog:p00-shared, so the
# shared :dev tags other labs use were left alone. The other images were the
# :dev ones already on the node. Each manifest went through sed first:
# namespace: bookstore became p00-shared-raw, the .bookstore.svc hostnames in
# DB_DSN, REDIS_ADDR and the migrate Job became .p00-shared-raw.svc, and the two
# image tags were replaced. The commands below show the file names only. Tabs in
# rabbitmqctl output are written as spaces, which is how the evidence check reads
# them.
