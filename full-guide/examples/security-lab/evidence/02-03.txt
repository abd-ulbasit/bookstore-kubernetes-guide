## step 5: clean up the probes and the namespaces (lab only)
# A silent delete of dns-probe in p02-bookstore ran just before the next line,
# so the pod was already gone when this command ran.
$ kubectl -n p02-bookstore delete pod dns-probe

$ kubectl delete namespace p02-other
namespace "p02-other" deleted
$ kubectl delete namespace p02-bookstore

# The namespace p02-other stayed Terminating while its probe Pod was still
# running on the shared node, so the Pod was force-deleted in its namespace.
$ kubectl -n p02-other delete pod dns-probe --force --grace-period=0
pod "dns-probe" force deleted from p02-other namespace
