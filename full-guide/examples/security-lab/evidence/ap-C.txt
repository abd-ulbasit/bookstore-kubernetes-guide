## the Norway problem: client dry run passes, server dry run refuses
$ cat cm-yes.yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: cm-yes
data:
  flag: yes
[exit 0]
$ kubectl apply --dry-run=client -f cm-yes.yaml -n lab-ns-c-open
configmap/cm-yes created (dry run)
[exit 0]
$ kubectl apply --dry-run=server -f cm-yes.yaml -n lab-ns-c-open
Error from server (BadRequest): error when creating "cm-yes.yaml": ConfigMap in version "v1" cannot be handled as a ConfigMap: json: cannot unmarshal bool into Go struct field ConfigMap.data of type string
[exit 1]
