# Transcript for 03-config-and-storage/05-stateful-data-patterns.md, lab steps 0 to 10.
# Tier A: a kind cluster with one node. Kubernetes v1.37.0, kubectl v1.37.2.
# Node runtime: containerd 2.3.4.
# Recorded by running examples/security-lab/labs/03-05.sh from full-guide/.
# The lab used the scratch namespace p03-05-stateful. The chapter names the
# bookstore namespace and applies the same files. Pod addresses are redacted
# to <pod-ip> in the output.
#
# The restore Pod reads a scratch Secret, db-credentials-restore, made from the
# 16- manifest with only its name changed. The shared db-credentials Secret is
# never patched in this run.
#
# In step 9 the first psql attempt over TCP was refused right after the Pod was
# Ready. The script then waits with pg_isready until TCP accepts connections,
# and every check after that connected. The run did not trace the Pod's phase at
# the refusal. The count in step 10 is taken right after the namespace delete.
# The script exits with status 1 because its last command finds no namespace.

## step 9: the database keeps the password it was initialised with; a Secret change is not applied
$ kubectl exec -n p03-05-stateful postgres-restore -- sh -c 'grep -v "^#" /var/lib/postgresql/data/pgdata/pg_hba.conf | grep .'

host    all             all             127.0.0.1/32            trust
host    all             all             ::1/128                 trust
local   replication     all                                     trust
host    replication     all             127.0.0.1/32            trust
host    replication     all             ::1/128                 trust
host all all all scram-sha-256
$ kubectl exec -n p03-05-stateful postgres-restore -- sh -c 'PGPASSWORD="$(cat /run/secrets/db/password)" psql -h <pod-ip> -U bookstore -d bookstore -tAc "select 1"'

$ OLD_PW=$(kubectl get secret db-credentials-restore -n p03-05-stateful -o jsonpath='{.data.POSTGRES_PASSWORD}' | base64 -d)

$ printf '%s' "$OLD_PW" | kubectl exec -i -n p03-05-stateful postgres-restore -- sh -c 'PGPASSWORD="$(cat)" psql -h <pod-ip> -U bookstore -d bookstore -tAc "select 1"'
