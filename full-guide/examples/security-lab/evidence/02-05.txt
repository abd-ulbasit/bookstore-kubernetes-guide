# Transcript for 02-networking/05-gateway-api.md, steps 1 to 4.
# Tier A: kind cluster sf-pilot on a Linux lab host, node image Kubernetes
# v1.37.0 (kind v0.33.0), kubectl v1.37.2, Helm 4.1.4. The lab host has no
# host port mapping, so the NodePorts are reached from inside the node container
# with docker exec, and the kubectl commands run from the author's shell.
# Gateway API CRDs: standard-install.yaml v1.7.0. Traefik chart 42.2.0,
# app v3.7.16, pinned by digest sha256:1336e85a...
# Namespaces: the lab names are p02-05-bookstore, p02-05-team-a, p02-05-team-b
# and p02-05-traefik, where the chapter says bookstore, team-a, team-b and
# traefik. The shared cluster rule requires the p02- prefix. Manifests are the
# repository files with the namespace renamed in a scratch copy. The team
# namespaces, their routes and the ReferenceGrant were written for the lab with
# the p02-05 names. The NodePort requests were sent from inside the kind node,
# with bookstore.localdev.me resolved to the node by curl --resolve.
# Values: the Traefik values file is the chapter's, with the namespace flag set
# to p02-05-traefik.
# What did not work the first time, kept in the transcript below:
#   1. image.versionOverride is a top-level key, not an image key. The chart
#      rejected the first values file.
#   2. The first helm install ran past the tool's time limit and left the
#      release in pending-install. It was uninstalled and installed again (part 3).
#   3. The scratch copy's rename also renamed the Gateway and HTTPRoute, so the
#      Gateway was deleted and the stack re-applied from the repository file.
#   4. With allowedRoutes switched to a label Selector, the Bookstore's own
#      route stopped attaching (Accepted=False, NotAllowedByListeners) until the
#      bookstore namespace carried the label too.
#   5. An apply to the shared cluster timed out in etcd and was re-applied.
# An earlier apply to a namespace named p02-bookstore, made by another worker,
# is not part of this run.
