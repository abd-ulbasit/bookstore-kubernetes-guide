# Transcript for 13-grand-capstone-bookstore-platform/11-backstage-developer-portal-idp.md, the
# token-scope checks and the restricted dry-run of the chapter's Backstage and
# Postgres pods (hands-on section 7). The last run's negative control (section 5)
# was refused for a missing default ServiceAccount, not by PodSecurity, so it is
# not evidence for the restricted profile and the chapter does not cite it.
# Lab cluster: a kind cluster on Kubernetes v1.37, kubectl client v1.37.2. The
# cluster and node names are as the lab printed them. The chapter prints the
# reader's names; this run used these stand-ins: namespace backstage is
# p13-11-backstage, namespace argocd is p13-11-argocd, the ClusterRole and
# ClusterRoleBinding backstage-catalog-reader are p13-11-backstage-catalog-reader.
# The rbac.yaml and backstage-application.yaml values are read from the
# repository with those names substituted, so the grants are the chapter's.
# The Backstage image is not built and the Argo CD Application is not applied:
# the lab has no Argo CD and no Backstage image. The chart is rendered with
# helm template and its pod templates are dry-run against restricted, which
# creates nothing. The helper that copies each pod template into a Pod is not
# committed. It adds a data emptyDir to the StatefulSet only, because the claim
# template supplies that volume at run time.
# The ExternalSecret and AppProject manifests were not dry-run, because the lab
# has no External Secrets or Argo CD CRDs.
# Recorded by running the commands below in order. Section 7 attempts to delete
# every object this run created. Two cluster-scoped deletes were refused and the
# identity could no longer read cluster-scoped objects, so the leftovers are
# listed in the chapter's review notes, not verified gone here.
