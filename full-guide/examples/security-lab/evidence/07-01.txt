# Transcript for 07-delivery/01-packaging-helm.md. Steps 0 to 2c and step 4
# are the checks the chapter prints: lint, render counts, the values schema,
# the provenance and scan of a third-party chart, and the plaintext Secret in
# the render. Step 3 holds the install attempts that failed before the
# namespace change in the chapter; they are kept as they ran. The cluster
# stopped answering the admin identity during step 3 (see the note at the end),
# so nothing after the install is captured.
# Lab: one Linux host running a kind v0.33.0 cluster named sf-pilot (a
# Kubernetes v1.37.0 node, the cluster is shared with other chapters), kubectl
# v1.37.2, Helm v3.22.1 (the chapter's pin), trivy v0.76.1, cosign on the
# author's workstation. Helm and kubectl run from the author's workstation
# against the cluster through a tunnel.
# Recorded by running the chapter's commands in order from full-guide/, with
# these substitutions, all named here: (1) the chart's namespace bookstore is
# p07-01-bookstore and the verification namespace bs-verify is p07-01-verify,
# as the captured runs use p07-<chapter> names; (2) the three hostnames the
# chart builds from bookstore (database.host, catalogConfig REDIS_ADDR and
# paymentsWorker amqpUrl) are set to the lab namespace in lab-values.yaml, and
# every helm command passes that file; (3) priorityClasses.create=false,
# because the cluster-scoped bookstore-* PriorityClasses already exist on the
# lab cluster and the chart does not adopt objects it does not own; (4) the
# cluster was not recreated and the four bookstore/*:dev images were already
# loaded. The cluster and node names are shown as the lab has them. Terminal
# colour codes are removed. Nothing else is edited.

# Stopped here. From about 08:04 PKT the admin identity in the lab kubeconfig
# was denied on every API call (`Forbidden: User "kubernetes-admin" cannot
# ...`), including reads of /version, namespaces and the cluster-wide RBAC
# objects. The author did not change RBAC or any cluster-scoped object and
# did not look for another identity. The namespace p07-01-bookstore was
# deleted in the cleanup above and was not re-created. Steps that need the
# cluster (the install itself, `helm get values`, the release Secret, the
# upgrade and rollback, the server dry-run into a restricted namespace and
# the operator toggles) are therefore not in this transcript. The chapter
# marks their output as illustrative.
