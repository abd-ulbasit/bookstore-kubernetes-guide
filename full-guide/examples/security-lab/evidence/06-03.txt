# names are replaced: tracing ran as p06-03-tracing and bookstore as
# p06-03-bookstore. Command lines that named a scratch directory show only the
# file name. Lines that name the local API tunnel port and the admin user are
# redacted; no output block in the chapter uses them. The node name is printed
# as the lab cluster reports it. The chapter says once that its output came
# from a lab cluster with a different name.
# Enforcement: the kind cluster's default CNI, kindnet, enforced the policies in
# step 3. The refused send in step 4 timed out after a 20-second wait.
# What did not work the first time:
#  - Nulling the Tempo chart's Jaeger receiver broke the render (helm template).
#    The Jaeger receivers stay on, and the chapter says so.
#  - Tempo's read-only root filesystem needed an emptyDir at /var/tempo for its
#    trace blocks and WAL, found from the rendered volumes.
#  - The first collector install hit an etcd request timeout. It was uninstalled
#    and reinstalled with the namespace substituted.
#  - Tempo's readiness probe returned 503 for about two minutes while its ring
#    warmed up, then passed without changes.
#  - The shared control plane flapped during the run. The controller manager lost
#    its leader lease, and the collector Deployment waited for its ReplicaSet.
#    kubectl calls returned RBAC errors or TLS handshake timeouts for minutes.
#  - The first in-cluster send timed out during the TLS handshake and succeeded
#    on retry. The cause was not traced further.
#  - A label change does not take effect at once. A send straight after the
#    relabel to catalog got through; the same send after a 20-second wait timed
#    out. The chapter's step 4 waits for that reason.
#  - The first collector release used the exporter key `otlp`. The chart renamed
#    it `otlp_grpc` at install, with a deprecation notice. The chapter uses the
#    new name. A later helm upgrade applied it (recorded below), and a first
#    upgrade attempt broke the receiver name and was rolled back to a fixed
#    revision.
#  - The collector logged one export deadline toward Tempo at 01:35:38 and
#    retried it. The trace query in step 5 returned the spans afterwards.
#  - A plain-HTTP probe of port 4318, made while debugging a TLS timeout, was
#    logged by the collector as an HTTP/2 preface error.
#  - The release history: revision 2 was the upgrade that renamed the exporter
#    key and also, through a bad substitution, the receiver. It crash-looped and
#    failed. Revision 3 applied the corrected values. The chapter's values equal
#    revision 3's apart from the namespace names.
#  - Four sends returned success: one before the first relabel (run outside the
#    logger), one inside the propagation window and two after restores. Tempo
#    returned three copies. The difference was not traced; the collector's one
#    export deadline at 01:35:38 is the likely cause.
#
