# Transcript for 08-day-2-operations/02-backup-and-dr.md, lab steps 1 to 9.
# Tier A: a kind cluster on Kubernetes v1.37.0, kubectl v1.37.2, Helm v4.1.4.
# Recorded by running examples/security-lab/labs/08-02.sh.
# The output in the chapter came from a lab cluster with a different name, and
# its namespaces carried the p08-02- prefix. The commands in the chapter use the
# reader's names (bookstore, velero); this transcript shows the lab's names,
# and the substitution is made only where the script builds a manifest.
# The chapter's velero namespace is restricted on its default path, so the lab
# name p08-02-velero carries no label above restricted and needs no entry in
# the exceptions registry. The chapter's privileged exception namespace is not
# applied here.
#
# Run: the Velero chart on the CSI snapshot path, in a restricted namespace,
# with a placeholder object store that does not resolve. The controller and
# its plugin ran and reported the storage location unavailable. The chart's
# CRD job ran in the same namespace. The node-agent exception was only
# dry-run, never installed.
# Not run: an object store, a snapshot-capable CSI driver, a backup and a
# restore. The cluster's storage class cannot take snapshots. The lab held
# the shared heavy-install lock and removed the chart, the CRDs and the
# cluster-scoped objects at the end (step 9).
#
# What did not work the first time: the probe Pod needs the namespace's default
# ServiceAccount, which appeared a few seconds late, so the script waits for it.
# The Velero image has no shell, so the probe mounts the image as a volume (the
# image-volume feature, which this cluster has) and reads /etc/passwd from it.
# The chart's one-shot CRD job has no resources value, so the namespace's
# LimitRange supplies its requests and memory limit.
#

## step 8: the three Velero objects, validated by the API server with strict field checks
$ chapter_yaml "kind: Restore" > restore-all.yaml
"$PY" -I - restore-all.yaml restore.yaml <<'PYEOF'
import re, sys
text = open(sys.argv[1], encoding="utf-8").read()
docs = [d for d in re.split(r"(?m)^---$", text) if "kind: Restore" in d]
open(sys.argv[2], "w", encoding="utf-8").write(docs[0])
PYEOF
"$PY" -I - velero-backup.yaml velero-schedule.yaml <<'PYEOF'
import re, sys
for name in sys.argv[1:]:
    text = open(name, encoding="utf-8").read()
    text = re.sub(r"(?m)^(  namespace: )velero\b", r"\g<1>p08-02-velero", text)
    open(name, "w", encoding="utf-8").write(text)
PYEOF
