# Transcript for 00-foundations/07-local-cluster-setup.md, the hands-on steps.
# Tier A: kind v0.33.0 with a Kubernetes v1.37.0 node, kubectl v1.37.2.
# The shared cluster sf-pilot stood in for the reader's bookstore cluster. Its
# kind node container is sf-pilot-control-plane; the chapter names the node
# bookstore-control-plane.
# Substitutions: every namespace the chapter calls bookstore ran as
# p00-bookstore, because sf-pilot is shared. kind create and kind delete were
# not run on sf-pilot. docker build and kind load were not run: the image was
# already on the node, and the crictl check below shows it. The namespace was
# deleted at the end in place of kind delete. The kind binary ran on the lab
# host; kubectl ran from a workstation. Another worker's p00-threat-demo
# namespace shares the cluster; this run did not touch it.
# What did not work the first time: the first apply ran from the repository
# root and failed with 'path does not exist'. The commands below were rerun
# from full-guide/, which is where the chapter's paths start.

## step 5: prove a NetworkPolicy is enforced
$ kubectl apply -f - <<'EOF'   # probe ServiceAccount and Pod, same baseline as catalog
serviceaccount/probe-sa created
pod/probe created
$ kubectl wait --for=condition=Ready pod/probe -n p00-bookstore --timeout=120s
pod/probe condition met
$ CATALOG_IP=$(kubectl get pod catalog -n p00-bookstore -o jsonpath="{.status.podIP}")
$ echo $CATALOG_IP
10.244.0.122
$ kubectl exec -n p00-bookstore probe -- wget -qO- -T 3 "http://$CATALOG_IP:8080/healthz"
{"status":"ok"}
$ kubectl apply -f - <<'EOF'   # default-deny ingress for the namespace
networkpolicy.networking.k8s.io/default-deny-ingress created
# Deliberate failure: the same request, now under the policy. Expect it to time out.
$ kubectl exec -n p00-bookstore probe -- wget -qO- -T 3 "http://$CATALOG_IP:8080/healthz"
wget: download timed out
command terminated with exit code 1
## step 6: remove the policy, then check the catalog image has no shell

$ kubectl exec -n p00-bookstore probe -- wget -qO- -T 3 "http://$CATALOG_IP:8080/healthz"
