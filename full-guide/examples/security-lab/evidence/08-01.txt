# Transcript for 08-day-2-operations/01-cluster-lifecycle.md, lab 08.01.
# Tier A: a kind cluster, Kubernetes v1.37.0 (kubelet and kube-apiserver),
# containerd 2.3.4, kubectl v1.37.2 client. Only the cluster server version is
# part of the evidence for the captured steps.
# Cluster: kind, context kind-sf-sched, three nodes (one control plane, two
# workers). The chapter says the output came from a lab cluster with a different
# name. Node names below are verbatim from that cluster.
# Substitutions: the chapter's commands name the namespace drain-demo; this run
# used p08-01-drain, and the script writes the same manifests with that name.
# The Deployment, ServiceAccount and PodDisruptionBudget keep the name drain-demo.
# Recorded by running full-guide/examples/security-lab/labs/08-01.sh against
# that cluster, after use_multinode.
# Run once, complete, exit 0.
#
# What did not work first, and was not used as evidence:
#   - The shared kind cluster used by other labs did not answer its API during
#     this session, so the run moved to the three-node cluster above.
#   - The three-node cluster's API server restarted several times during the
#     first attempts. Those attempts showed TLS handshake timeouts, EOF and
#     Forbidden errors. Attempts taken while the server was restarting were
#     discarded, and the run below was taken after it had been stable.
#   - An early draft spread the replicas with preferred anti-affinity, and then
#     with required anti-affinity. One worker carried a NoSchedule taint set for
#     other workloads, so the replicas could only run on the other worker, and
#     the replacement pod stayed Pending. The final script uses no affinity and
#     drains the untainted worker, so the two replicas sit on that worker and the
#     drain has something to refuse.
#   - An early draft edited the PodDisruptionBudget with sed -i, which BSD sed on
#     macOS rejects. The script writes a relaxed copy instead; the final run does
#     not relax the budget, so that step is not in this transcript.
#
