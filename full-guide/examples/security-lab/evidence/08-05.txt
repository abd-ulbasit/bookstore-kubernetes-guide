# Transcript for 08-day-2-operations/05-operators-and-crds.md, lab steps 1 to 12.
# Tier A: a kind cluster, Kubernetes v1.37.0 server, kubectl v1.37.2, Helm v4.1.4.
# Chart cnpg/cloudnative-pg 0.29.1 (operator 1.30.1). Steps 1 to 12 only read,
# render or dry-run: nothing was installed. The run asked for the namespaces it
# created to be deleted at the end; step 12 shows what happened.
# Recorded by running examples/security-lab/labs/08-05.sh from the guide's root
# with NS_CNPG=p08-05-cnpg-system and NS_BOOK=p08-05-bookstore. The chapter
# prints cnpg-system and bookstore; the captured lines carry the prefixed names.
# The cluster has a different name from the guide's, and the output does not
# show it. The chapter's step 7 command reads the Cluster file from standard
# input, which is why that output says STDIN.
#
# What changed in this run: the migration Pod carries serviceAccountName
# migrate-sa and the app: db-migrate label, and step 8 creates the Bookstore
# ServiceAccounts first. The operator objects carry resource requests and a
# memory limit (step 10). The network policies are dry-run (step 11). The
# privileged Pod refusal is no longer repeated here: chapter 08.04 shows it.
#
# What did not work the first time: client-side apply of the chart's CRDs
# (step 6) refuses the clusters and poolers CRDs, because the last-applied
# annotation kubectl adds exceeds the 256 KiB limit. Server-side apply (step 6b)
# accepts all eleven. A first run also dry-ran Pods before the namespace's
# default ServiceAccount existed, which gave a ServiceAccount error instead of
# the admission result. Step 8 now waits for that ServiceAccount.
#
# Step 12 timed out. Both namespaces were still Terminating about nine minutes
# later, while other namespaces on the shared cluster were in the same state.
# What remained in them was the lab's own ServiceAccounts, Role, RoleBinding
# and quota.
#
# Not run: the operator install, the Cluster, the failover, the DB_DSN rewire
# and the migration against a live database. The shared cluster was in use by
# other lab work, so those chapter steps are reader steps with no captured output.
