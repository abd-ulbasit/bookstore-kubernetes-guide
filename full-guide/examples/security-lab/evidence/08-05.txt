# Transcript for 08-day-2-operations/05-operators-and-crds.md, lab steps 1 to 12.
# Tier A: a kind cluster, Kubernetes v1.37.0 server, kubectl v1.37.2, Helm v4.1.4.
# Chart cnpg/cloudnative-pg 0.29.1 (operator 1.30.1). Steps 1 to 12 only read,
# render or dry-run: nothing was installed. Namespaces created by the run were
# deleted at the end.
# Recorded by running examples/security-lab/labs/08-05.sh from full-guide/ with
# NS_CNPG=p08-05-cnpg-system and NS_BOOK=p08-05-bookstore. The chapter prints
# cnpg-system and bookstore; the captured lines carry the prefixed names. The
# cluster has a different name from the guide's, and the output does not show it.
#
# What did not work the first time: client-side apply of the chart's CRDs
# (step 6) refuses the clusters and poolers CRDs, because the last-applied
# annotation kubectl adds exceeds the 256 KiB limit. Server-side apply (step 6b)
# accepts all eleven. A first run also dry-ran Pods before the namespace's
# default ServiceAccount existed, which gave a ServiceAccount error instead of
# the admission result. Step 8 now waits for that ServiceAccount.
#
# Not run: the operator install, the Cluster, the failover, the DB_DSN rewire
# and the migration against a live database. The shared cluster was in use by
# other lab work, so those chapter steps are reader steps with no captured output.
