# Tier A: kind cluster on a lab machine, Kubernetes v1.37.0 node, kubectl v1.37.2.
# The lab cluster is shared, so the run used scratch namespaces, and the example
# files were copied with only the namespace rewritten. The chapter's bookstore-ml
# is p12-04-ml in the Job and NetworkPolicy steps. The baseline check namespace is
# recorded as pss-check-baseline, and the restricted check uses p12-04-ml.
# The operator Pod checks came from a script file with the same steps as the
# chapter's one-liner. The chapter shows the one-liner.
# The kind load and the image build ran on the lab machine through its ssh
# wrapper, which is left out here.
# Not run: the Kubeflow Training Operator and KubeRay were not installed (the
# shared heavy-install lock was held). The operator checks use the pinned upstream
# manifests and chart, rendered and dry-run. The training image build did not
# finish on the busy lab machine, so the Job was dry-run only and no training Pod
# ran.
# Later re-runs of the operator Pod checks were refused: new namespaces did not
# receive their default ServiceAccount while the lab control plane was unhealthy.
# Those refused attempts are left out of this record.
# Paths on the lab machine are shown as <scratch> and <repo>.
